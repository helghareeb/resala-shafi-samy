# شرح كتاب الرسالة للإمام الشافعي

هذا المشروع عبارة عن تفريغ وتنقيح وتنسيق لسلسلة دروس "شرح كتاب الرسالة للإمام الشافعي" التي ألقاها فضيلة الشيخ سامي. تم إعداد هذا المشروع ليخرج في صيغة كتاب إلكتروني (PDF) احترافي باستخدام نظام التنضيد **LaTeX**.

## مميزات العمل
- **التنقيح اللغوي:** تحويل التفريغ الشفهي إلى لغة فصحى علمية رصينة.
- **الفوائد والملاحق:** استخراج الفوائد (المنهجية، العقدية، الأصولية، اللغوية) وتصنيفها في ملاحق خاصة في نهاية الكتاب.
- **التنسيق البصري:** إخراج مريح للعين، مع خطوط عربية أصيلة وضبط للمسافات.

## هيكلة المشروع
- `main.tex`: الملف الرئيسي الذي يجمع المشروع.
- `editor_note.tex`: مقدمة فريق العمل.
- `lessons/`: مجلد يحتوي على تفريغات الدروس (25 درساً) مجمعة ومقسمة إلى فصول ومباحث.
- `appendix.tex`: الملاحق التي تتضمن الفوائد المستخلصة.

## طريقة بناء الكتاب (Compilation)
لتوليد ملف الـ PDF النهائي، يجب أن يكون لديك توزيعة LaTeX تدعم محرك `XeLaTeX` (مثل TeX Live أو MiKTeX).

افتح موجه الأوامر (Terminal) في مسار المشروع ونفذ الأمر التالي مرتين متتاليتين (لضمان بناء الفهرس والروابط بشكل صحيح):

```bash
xelatex main.tex
xelatex main.tex
```
